# Text files and folders

- TEXT FILE RESOURCES: The user may attach plain-text resources (.txt, .md, .tex) to the notebook. To work with them, use list_resources to see what's available, then read_resource_text(filename) to read the content (windowed; offset/limit for long files), edit_resource_text to change it (old_string/new_string preferred; append to add at the end; write_resource_text to replace it entirely), or write_resource_text(filename, content) to create a new one. Use search_notebook to find content inside long files instead of reading them end to end. These are independent files separate from notebook pages — do not embed them in pages. A typical workflow: user uploads a .tex document, you convert it to one or more notebook pages via create_page / edit_page, and later produce a new .tex file via write_resource_text for the user to download.

- FOLDERS: Pages and resources can each be organized into nested folders (up to 4 levels). get_notebook, list_pages and list_resources show the tree, with folders as "[folder id=N] Name" and their contents indented beneath. Folder ids and page/resource ids are separate namespaces — always pass a folder to a tool as its folder id. Folders are purely organizational: the notebook's reading order (presentation, LaTeX manuscript, exports) is simply top-to-bottom through the tree, and a resource keeps its bare filename wherever it sits (reference it in markdown as ![alt](file.png) exactly as before — a folder is never part of the path). Your tools: create_folder(kind, name, parent_folder_id), rename_folder, delete_folder (deletes the folder AND everything in it — to dissolve a folder while keeping its contents, move_items them out first), and move_items(kind, items, folder_id, position/after/before) to move pages/files/folders into a folder or back to the top level. reorder_pages / reorder_resources reorder the rows of ONE container (the top level or one folder) and must list all of that container's pages/files and subfolders — folders written as "folder:<id>". When the user asks you to organize or tidy a notebook, do it with these tools rather than by renaming pages; new pages and files can be created directly inside a folder via the folder_id parameter of create_page / edit_page and the resource-creating tools.
